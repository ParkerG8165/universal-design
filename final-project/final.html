What: Foundational Concepts & Standards

Understanding how humans perceive and interact with digital interfaces starts with established design principles and assistive specifications.

Norman’s Design Concepts

Introduced by cognitive scientist Don Norman, these principles explain how users intuitively understand physical and digital objects:

  • Affordances: The possible actions an object allows (e.g., a button affords clicking or pressing).
  • Signifiers: Visual or auditory cues that communicate where the action should take place (e.g., underlines on links, contrast borders on buttons).
  • Feedback: Immediate, clear responses confirming that an action occurred (e.g., focus rings, form submission alerts).
  • Conceptual Models: Designing interfaces that match the user’s mental expectation of how a system works.

User-Centered Design (UCD)

User-Centered Design is an iterative design framework that places real users—including people with visual, auditory, motor, and cognitive disabilities—at the center of every stage of product development. Rather than forcing users to adapt to technology, UCD relies on user research, usability testing, and continuous feedback to build intuitive experiences.

WAI-ARIA

Web Accessibility Initiative – Accessible Rich Internet Applications (WAI-ARIA) is a technical specification published by the W3C. It bridges accessibility gaps in dynamic web content and custom UI components (such as tabs, modals, and live regions) by supplying semantic roles, states, and properties to assistive technologies like screen readers when native HTML is insufficient.

Interaction Design Theory

Interaction Design (IxD) focuses on the dialogue between a person and a system. Key dimensions include words, visual representations, physical objects/space (such as touchscreens or keyboards), time, and behavior. Strong IxD minimizes cognitive load, prevents user errors, and ensures predictable navigation pathways across all input methods.

Why: Demographics, Mobile & Inclusion

Designing accessibly is not an edge-case consideration—it directly impacts billions of users and improves usability across every device.

Disability Demographics

According to the World Health Organization (WHO), over 1.3 billion people—roughly 16% of the global population—experience significant disability. In the United States alone, more than 1 in 4 adults live with a disability affecting mobility, cognition, hearing, or vision. Furthermore, disabilities can be:

  • Permanent: Blindness, deafness, or limb loss.
  • Temporary: A broken arm, ear infection, or recovery from eye surgery.
  • Situational: Reading a screen in bright sunlight, holding a baby in one arm, or watching video in a noisy environment.

Mobile Web

The majority of global web traffic originates on mobile devices. Mobile browsing shares direct overlap with accessibility principles: small viewports require reflowable layouts without horizontal scrolling, touchscreens demand generous target sizes and spacing, and outdoor environments require high color contrast to remain legible.

Accessibility as a Core Standard

Web accessibility is both a civil right and a catalyst for better engineering. Adherence to the Web Content Accessibility Guidelines (WCAG) reduces legal risk, strengthens search engine optimization (SEO) through clean semantic markup, and delivers faster, clearer interfaces for every visitor regardless of ability or device.

How: Accessible Code & Layout Techniques

Practical HTML and CSS patterns ensure assistive technologies can parse content accurately while keeping visual layouts clean and responsive.

Forms and Tables

Data tables and user input forms require explicit programmatic relationships so screen readers can announce headers and labels accurately.

  • Tables: Always include a <caption>, use <th> elements for headers, and define scope="col" or scope="row".
  • Forms: Pair every input with a visible <label> using matching for and id attributes, and group related controls with <fieldset> and <legend>.

Accessible CSS

CSS controls visual presentation without altering document semantics. Best practices include:

  • Color Contrast: Maintain at least a 4.5:1 contrast ratio for body text and 3:1 for large text and UI borders. Never convey meaning by color alone.
  • Visible Focus States: Never remove browser outlines without providing a high-contrast :focus-visible replacement for keyboard users.
  • Relative Units & Motion: Use rem and em units so text scales smoothly when users zoom to 200%, and wrap animations in @media (prefers-reduced-motion: reduce).

Grids and Flexbox

Modern CSS Grid and Flexbox replace brittle HTML table layouts while supporting responsive reflow across screen sizes. However, visual order must match DOM source order—avoid using CSS order or flex-direction: row-reverse to rearrange interactive elements, as keyboard focus follows the HTML source order rather than the visual layout.
